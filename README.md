# MediaLab Academy — 14-дневный курс мультимедиа

Готовый адаптивный сайт для GitHub Pages. 14 уроков, поиск, фильтры, личные заметки, чек-листы, таймер, портфолио, импорт и экспорт прогресса.

## Исправлена проблема с загрузкой уроков

В предыдущей версии браузер мог блокировать `fetch('lessons.json')`, когда `index.html` открывался как локальный файл (`file://`). Теперь все уроки встроены в `data.js`, а `app.js` использует `window.COURSE_LESSONS` **без fetch**. Поэтому сайт работает даже при двойном щелчке по `index.html` без сервера.

## Проверка локально

1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Перейдите в «Все уроки» и откройте любой день.
4. Отметьте урок и перезагрузите страницу — отметка должна сохраниться.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub, например `medialab-course`.
2. Загрузите **содержимое** ZIP в корень репозитория, чтобы `index.html`, `data.js`, `app.js`, `styles.css` лежали рядом.
3. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main`, каталог `/(root)`.
4. Сохраните и дождитесь публикации.
5. Адрес будет `https://ВАШ-ЛОГИН.github.io/medialab-course/`.

## Состав

- `index.html` — страница сайта
- `styles.css` — адаптивное оформление
- `data.js` — встроенные уроки, работают без сети
- `app.js` — навигация, таймер, прогресс, заметки, портфолио
- `lessons.json` — удобная копия содержания для редактирования
- `.nojekyll` — служебный файл GitHub Pages

**Как изменить уроки:** правьте массив `window.COURSE_LESSONS` в `data.js`. `lessons.json` — резервная читаемая копия, не загружается сайтом автоматически.

**Хранение:** прогресс и портфолио сохраняются в localStorage текущего браузера, не на сервере. Для переноса используйте кнопки «Экспорт» и «Импорт».

**Важно:** используйте медиаматериалы с подходящими лицензиями. Доход после обучения не гарантируется.
